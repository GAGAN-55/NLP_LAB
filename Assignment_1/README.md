
# Restaurant Review Sentiment Analysis

This project uses Natural Language Processing (NLP) and Machine Learning to classify restaurant reviews as positive or negative.

## Features
- Dataset creation and CSV storage
- Text preprocessing, stemming, and lemmatization
- Feature extraction using Bag of Words and TF-IDF
- Sentiment classification using Naive Bayes and Logistic Regression
- Model evaluation and prediction on new reviews

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn

## Dataset
The dataset contains 60 restaurant reviews, including 30 positive and 30 negative reviews.

## Output
The program generates a CSV dataset, evaluates both machine learning models, compares their accuracy, and predicts sentiment for new reviews.
